1. Feature Engineering & Split

80% Train / 20% Test Split: We properly partition the dataset prior to any scaling to prevent data leakage.

Derived Physical Features:

  • Water–Cement Ratio = Water / Cement
  • Binder Content = Cement + Slag + Fly Ash
  • Aggregate Ratio = Fine Aggregate / Coarse Aggregate

2. Deep Learning Autoencoder

An Autoencoder is a deep neural network that learns highly efficient, non-linear representations of data without human supervision.

  • Encoder: Compresses the 11-dimensional raw input into a refined 32-dimensional "bottleneck" state, stripping away noise.
  • Decoder: Validates this bottleneck by attempting to reconstruct the input.
  • Output: We pass only the mathematically pure bottleneck variables directly into the PLS model, improving regression robustness.

3. Graph Neural Network (GNN) vs Deep Residual PLS

Graph Neural Networks (GNN) look at the entire dataset as a connected "network" of nodes (samples). They evaluate how similar concrete mixtures relate to each other mathematically, passing messages between related samples to find structural patterns. While powerful, they often over-smooth regression data.

Deep Residual Probabilistic PLS (Our Model) takes a different approach:

  • It trains standard PLS on the Autoencoder features and computes the residual error.
  • It repeatedly trains new layers specifically targeting the errors left by previous layers.
  • It fuses these outputs together, enforcing rigorous RMSE minimization without GNN's over-smoothing effect.
